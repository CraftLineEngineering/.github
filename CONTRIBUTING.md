# Contributing to CraftLine Engineering repositories

Thanks for your interest in contributing. We aim for small, high-quality changes with clear intent and strong defaults.

## Code of Conduct
Be respectful and constructive. Assume good intent.

## How to contribute
- Open an issue first for non-trivial changes
- Use focused branches: feat/, fix/, chore/
- Keep PRs small and well-documented

## Development
```bash
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
```

Run tests and linters before opening a PR.

## Security
Never commit secrets. Use environment variables or secret managers.
